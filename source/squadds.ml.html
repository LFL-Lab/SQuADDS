squadds.ml.client module#

Client of the SQuADDS ML API (the models hosted on the SQuADDS Hugging Face Space).

from squadds.ml import client client.list_models() client.get_model(“transmon_cross_hamiltonian_inverse”) # inputs, outputs, units, limits, example request client.predict(“transmon_cross_hamiltonian_inverse”, inputs={“qubit_frequency_GHz”: 4.85, “anharmonicity_MHz”: -205.0}) client.predict(“<file model id>”, file=”chip.gds”, inputs={“ground_layer”: “1/0”})

The base URL is SQUADDS_ML_API_URL when set, else DEFAULT_URL. Gated models need a Hugging Face token of a member of the SQuADDS organization (token= or HF_TOKEN).
