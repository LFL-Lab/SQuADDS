SQuADDS#

A validated design database and simulation workflow for superconducting qubits

SQuADDS gives you a well-characterised starting point for superconducting hardware. Ask for the Hamiltonian you want and get the closest pre-simulated designs from an experimentally validated database, an interpolated best guess, and, from version 0.5, the full capacitance matrix of any planar layout straight from its GDS file.

pip install SQuADDS

Python 3.11 or newer. For the capacitance models: pip install "squadds[ml]". From source with uv sync: installation guide.

Where to start#

Qubit designers

Find a design for your Hamiltonian

Give target parameters, get the closest pre-simulated designs and an interpolated best guess to simulate.

Tutorial 1Tutorial 2

db = SQuADDS_DB()
db.select_system("qubit")
db.select_qubit("TransmonCross")
db.create_system_df()
Analyzer(db).find_closest(
    {"qubit_frequency_GHz": 4,
     "anharmonicity_MHz": -200}, num_top=3)

Layout to capacitance

Capacitance matrix from a GDS file

The full N × N Maxwell matrix of every conductor, ground included, in about a second on a CPU. Nets are never merged.

ML models guideTutorial 11

predictor = CapacitancePredictor(
    load_model("QCap"))
res = predictor.predict("chip.gds")
res.to_dataframe()   # fF, ground first
