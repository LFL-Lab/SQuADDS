squadds.ml.capacitance package
==============================

Planar capacitance models (optional extra: ``pip install "squadds[ml]"``): GDS layout -> full N x N Maxwell capacitance
matrix (fF, ground first). Guide: :doc:`ml_models`. ``squadds.ml.capacitance.dataset`` and ``squadds.ml.capacitance.qc``
work without the extra (the GDS checks of ``qc`` need gdstk and shapely).
